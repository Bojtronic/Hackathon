# AI Copilot for Renewable Energy Data Rooms


An intelligent assistant that automates document analysis and due diligence for renewable energy projects using AI and natural language processing.

## Features

- 🔍 **Natural Language Querying** - Ask questions in plain English about your documents
- 📑 **Multi-Format Support** - Process PDFs, Word docs, Excel files, and scanned texts (OCR)
- 🔗 **Source Referencing** - Every answer includes exact quotes with page numbers and file sources
- ✅ **Checklist Auto-Filling** - Upload Excel checklists to be automatically populated from documents
- ⚡ **Fast Processing** - Handles large document sets (10,000+ pages) efficiently


### Prerequisites

- Python 3.10+
- OpenAI API key
- Tesseract OCR (for scanned documents)
